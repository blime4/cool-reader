# 书间 FOLIO · 万物收藏

在 FOLIO 阅读器基础上，收藏阅读中遇到的植物、动物与鸟类。

## 启动

需要 Windows、Node.js22+。无需安装 npm 依赖。

运行 `npm start`，打开 http://127.0.0.1:4173 。也可以双击项目中的「启动植物志.cmd」或 scripts/launch.cmd（旧文件名保留兼容已安装启动器）。

GitHub Pages 入口：https://blime4.github.io/cool-reader/ 。当前用户首次使用需执行：

    powershell -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\install-protocol.ps1

Pages 只是启动入口，点击按钮通过已注册 folio-plants://start 启动本机固定服务，浏览器可能要求确认打开应用。项目移动后重新注册。卡片、配置和 Obsidian 内容不会上传 GitHub。

## 万物收藏

查询范围可选全部、植物、动物、鸟类；动物范围包含鸟类。候选卡片标注类群、精确/别名/名称片段匹配及来源链接。收藏后可按类群、认识状态、书名或笔记筛选。

类群根据资料源的分类学信息确定，不从名称猜测；未确定的类群显示其他。手动记录时可自行选择类群。旧卡片没有 kind 字段时按植物读取。不同界的同名学名不会被混为一个物种。

查询优先命中本地离线名录，再联合 GBIF、iNaturalist 与维基百科 / Wikidata。离线名录包含 16,544 条参考记录：11,022 个鸟种、5,506 个其他动物种，以及 16 个常见科属、苔藓类群与阅读用字入口；12,988 条物种记录带中文名。支持简繁体、英文名、已收录的旧学名别名，以及明确标注为“待核对”的原书用字线索。离线命中立即返回，无需等在线接口超时。

例如「鹪鹩」可找到当前名录中的 Nannus troglodytes，旧学名 Troglodytes troglodytes 也可检索；「啄木鸟」先提供啄木鸟科 Picidae，再列出相关具体鸟种。科、属、目等类群会明确标注，不冒充已经确认的具体种。中文俗名仍须结合原书核对。

暂未找到资料或网络中断时，可以直接选择「先收纳」建立待核对卡片，不必填写拉丁名；此类卡片不会虚构学名、图片或资料网址。未知类群默认「其他」，可自行改为植物、动物或鸟类。

离线物种名录来自 [Cornell BirdNET+ Taxonomy v0.4-Oct2026](https://birdnet.cornell.edu/taxonomy/download)，名称及分类元数据保留 [MIT 许可](dist/nature-catalog-LICENSE.txt)；补充科属入口来自 [GBIF](https://techdocs.gbif.org/en/openapi/v1/species)。仅提取名称、分类和标识，不复制生成式物种简介。dist/nature-catalog.json 保留版本、来源地址、原始 CSV SHA-256 和计数；scripts/build-nature-catalog.ps1 可从同一 CSV 重建，更新数据前须核验新版本及许可并更新固定校验值。

图片按单张许可筛选并保留作者署名，排除版权专有及禁止演绎的照片；主图不可用时从 Avicommons 补充授权图片。当前 16,528 个物种中有 15,678 个具备授权实图，其中 3,396 张来自补充来源。「鹪鹩」和「啄木鸟」搜索中常见的 10 个具体鸟种已附带本地照片，来源、许可及校验值见 dist/plant-assets/nature-photo-credits.json。科级卡片可用明确标注具体鸟种的代表图，不表示科内所有成员都具有相同外观。

所有图片区域从加载开始就显示有名称的示意封面；有可靠图片时显示实图，超时、加载失败或尚无授权图片时保留标为「名称封面 · 待补实拍」的图像，避免空白。示意封面不会写入卡片的实拍图片字段，收藏页和书引使用同一套显示逻辑。

## Obsidian 与可读文件名

项目根目录 config.local.json（被 Git 忽略）：

    {"obsidianVault":"你的库的绝对路径","obsidianFolder":"FOLIO植物志"}

原有管理目录 FOLIO植物志 保留兼容，不移动其他笔记。新卡片使用物种名称作为文件名，例如「金合欢属.md」。稳定 id 保留在 YAML 属性中，与文件名分离。

启动时会把旧 UUID 文件名安全迁移为名称，逐字节保留卡片内容。若名称已经被其他文件占用，不覆盖原文件，而使用「名称 (编号).md」等区分名。非法文件名字符、Windows 保留名及大小写/规范化碰撞都会处理。新文件通过排他创建防止检查后的竞争覆盖。手动在 Obsidian 改名的卡片仍能识别。

网页修改物种名称时会同步调整文件名；覆盖自己的旧版本前会核对内容并存入专用「快照」，发现外部编辑则提示刷新。删除会移入专用「已删除」目录。Markdown 正文的「## 阅读笔记」及缩进保留，可以直接在 Obsidian 编辑。不要删除 id 或 folioPlant 管理标记（旧属性名保留兼容）。

旧 data/plants.json 首次迁移后保留备份，不重复导入。图片在专用「附件」中。迁移整套收藏时复制整个管理文件夹（含附件、快照、已删除、迁移标记）。单独 JSON 备份不含图片二进制文件。

## 阅读工作台联动

在 config.local.json 中增加 `readingBookPath`，填写本机 EPUB 的绝对路径，重启服务后打开 `/index.html`。例如：

    {"obsidianVault":"你的库的绝对路径","obsidianFolder":"FOLIO植物志","readingBookPath":"C:/Books/自然笔记.epub"}

工作台自动打开这本书并记住阅读位置；首次优先定位「1月1日／一月一日」章节，其他书籍从首个可读页开始。当前配置支持一本 EPUB，大小不超过 25 MiB。书籍内容只由本机服务提供，不发布到 GitHub Pages；进度保存在被 Git 忽略的 data/book-progress.json 中。更换书籍内容会产生新的书籍标识，不沿用旧书的位置。

- **这一页的自然**：显示原文实际出现的自然词语，点击查询物种并携带书名、章节、重排页和原文片段。
- **书引**：把书页中实际出现的名称用细线连接到图片卡片，优先使用已有收藏的照片。图片保留署名，名称匹配仍需核对物种；没有图片时可以继续查询。翻页或收起书本时隐藏旧连线，避免引用错页。
- **收藏这段遇见**：选中原文后点击按钮，再填写要认识的物种名称；对外查询仅发送名称。
- **自然足迹**：在全书中寻找已收藏物种的名称，点击相遇位置回到书页。
- **回到书中**：保存有阅读位置的卡片可跳回原文并高亮引用；收藏页也提供继续阅读入口。

再次遇见已有物种会打开原卡片，保存后将新引用和返回链接追加到笔记，保留原有主要来源及笔记。同书旧卡片可以补齐缺少的阅读标识。普通编辑不会自动带入另一段阅读来源。

线索和足迹是字面匹配，需要自行核对具体物种；未识别出的名称也可以手动查询。界面页码是工作台生成的重排页，不是纸书页码。配置书库采用自然线索视角，示例和手动上传的书籍仍支持原有的人物视角。

翻页时保留当前正文，纸张过渡结束后再更新页码与阅读来源。连续点击会合并到最后希望到达的位置；切换书籍或收起书本会清理正在进行的翻页。系统开启「减少动态效果」时直接切换页面。

## 开发与检查

    node --test tests/*.test.mjs

- dist/：本地界面与原阅读工作台
- docs/：GitHub Pages 静态启动页
- lib/：查询、分类、本地与 Obsidian 存储
- scripts/：固定路径的本机启动器
- data/、work/、outputs/、config.local.json：不提交、不公开

本地接口只监听回环地址，保留 Host/Origin 校验。启动器不会执行网址传入的命令，也不会结束占用端口的其他程序。
