把自然，留在身边。Read. Observe. Remember.每一次收藏，都是一个故事的开始。

第一次来，准备三件小事。

YOUR FIRST VISIT
01

准备本地项目

从 GitHub 下载完整项目并保存在这台电脑，安装 Node.js LTS，在项目目录运行 npm install。

02

注册一次启动器

在项目目录运行下方的注册命令。仅为当前 Windows 用户添加启动入口，无需管理员权限。

03

从网页，一键回家

点击上方“启动本机植物志”，确认浏览器提示。启动器会打开本机工作台，已运行时直接复用。

安装命令与启动排查

在完整项目文件夹内打开 PowerShell，运行一次：

powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\install-protocol.ps1

如果点击后没有反应，先完成注册，再重试并允许浏览器打开应用。也可以双击项目中的 scripts\launch.cmd 直接启动。项目移动到新文件夹后，请重新注册。若下载文件被 Windows 阻止，请先查看脚本内容，再在脚本文件的属性中解除阻止。

启动器只运行固定的本地服务，不使用网页传入的命令或路径。如果端口 4173 被其他程序占用，会提示错误，不会结束其他进程。换一台电脑时，需要在那台电脑重新安装本地项目和启动器。
